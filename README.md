# Personal Portrait Writing

Write a personal portrait from the subject's own writings, structured by character lines instead of chronology, with every quote verified verbatim against its source.

## How it works

1. **Collect the materials first.** Proactively ask the user for three kinds: the subject's own social accounts (blogs, tweets, posts, letters — official exports preferred), web-search leads (third-party coverage, photos taken by others, interviews), and materials the user hands over directly. Research and compile before writing: check, deduplicate, sort along a timeline, write a source list.
2. **Distill three or four character lines.** Each line is one sentence that sums the person up. Keep only the material that illuminates a line. Contradictions are the skeleton — put both sides next to each other.
3. **Write with representative episodes and details.** One section, one character line, one or two scenes. Slow the camera down: time, place, action, and the subject's own words.
4. **Verify every quote word for word** against the original text, in both simplified and traditional Chinese. A post's date is its publishing date, not the event's date.
5. **Accept the subject's corrections everywhere**, and keep private matters out unless the subject asks for them.

## Install

- **Any agent (generic version):** `npx skills add personal-portrait-writing`, or `clawhub install personal-portrait-writing`, or copy `skills/personal-portrait-writing/` into your skills directory.
- **Muse:** use the variant in `muse/` instead — copy `muse/SKILL-MUSE.md` as `SKILL.md` plus `muse/skill.yaml` into your Muse skills folder. It keeps the `muse.exec` / `muse.read` tool references.
